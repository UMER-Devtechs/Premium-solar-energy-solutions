# project
---
## 📦 Dependencie
- Node.js : v20.11.0
- npm: 10.2.0 
- Redis: 7.1.1 
- MongoDB: 7.0.8 
- TypeScript: 5.1.3
## 💻 Installation
To install the required packages for this repository, use the following command:
```bash
npm install
```
or
```bash
npm i
```
## 🛠️ Building
To build packages for the server or for production, run the following command:
```bash
npm run build
```
## 🚀Running
To run and watch the application at runtime, use the following command:
```bash
npm run dev
```
To start the server, execute the command:
```bash
npm run prod
```
